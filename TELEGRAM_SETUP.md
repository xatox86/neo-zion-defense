# Telegram Mini App

1. Создайте бота в @BotFather командой `/newbot`. Храните токен в секрете; для этой статической игры он не нужен в коде и не должен попадать в репозиторий.
2. Опубликуйте приложение по HTTPS через GitHub Pages и убедитесь, что адрес открывается.
3. В @BotFather откройте настройки бота и настройте Main Mini App, указав опубликованный HTTPS URL. Также можно создать Direct Mini App командой `/newapp` и следовать подсказкам BotFather.
4. Поделитесь ссылкой `https://t.me/<BOT_USERNAME>?startapp` для Main Mini App или `https://t.me/<BOT_USERNAME>/<APP_SHORT_NAME>` для Direct Mini App. Вставьте ссылку в сообщение группы и закрепите его.
5. Проверьте на iOS и Android внутри Telegram. Интерфейс BotFather может меняться. Круглосуточный бот-сервер для открытия статического приложения не нужен.

Данные Telegram на клиенте не являются серверной авторизацией.
