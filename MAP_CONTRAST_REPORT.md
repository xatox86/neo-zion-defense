# Map contrast review — 2026-11-08

Working branch only; published main is preserved at `backup/main-before-map-contrast-20261108`. Three cold underground terrain assets were derived separately from their corresponding existing maps and the user reference. Existing route and slot IDs were preserved, including their prior gameplay and save compatibility. New EMP dome sprites have individual source bounds rather than slices from the uneven atlas. Turret materials are brightened, with a local contrast backdrop and contact shadow. Selection of a built tower uses conservative visual bounds independent of hit zones and range. The rail pivot, aiming and muzzle origin use the same geometry.

## Evidence and limitations

`artifacts/map-contrast/before-N.png` and `after-N.png` compare the published game and this branch at 390×844 with the same two starting towers. `map-N-empty.png`, `map-N-four.png` and `map-N-battle.webm` are captures of the actual running game; four-tower and video setup grants test energy. `map-N-all-levels.png` is a deliberately injected 12-tower arrangement and `map-N-tower-grid.png` is a renderer test harness; neither demonstrates a legitimate economy run. The route debug screenshots show the actual route and touch areas over the terrain. The route on the third map passes very close to the last platform; its visual clearance needs further manual review before release. Automated selection/build tests do not establish artistic alignment.

At 360×740, 390×844 and 430×932, all 39 slots were selected, built, upgraded and sold at zoom 1.15 with test energy. Focus bounds were checked at each slot, at three zoom levels, on three viewport sizes; a separate touch test selects four tower types at zoom 2.5 on all maps. Forty-eight tower poses were rendered against visual bounds, and the three separate dome images have no strong alpha touching the edges. Compact/expanded Telegram viewport was simulated in desktop Chrome; this is not a physical iPhone or Telegram test. Legacy save tests include an injected completion state.

Headless desktop Chrome emulation, 390×844, 13 enemies: approximately 59.5 FPS high and 30 FPS low in an 8-second sample. JavaScript heap is not total browser, image or GPU memory and this is not a device benchmark. The three new terrain files total 946,716 bytes versus 1,449,660 bytes for the previous three; the three dome files add 96,814 bytes and the lit hardware image adds 387,274 bytes high / 100,878 bytes low in place of the existing hardware image. Measurements are stored in `artifacts/map-contrast/performance.json`.

Next: manually review clearance of the final platform on map 3, test on a physical iPhone inside Telegram, evaluate real-world readability and frame rate, and confirm readiness before any deployment. Production release requires the user's separate command.
