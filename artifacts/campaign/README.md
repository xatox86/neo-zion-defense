# Проверка кампании и выживания

Пять операций и отдельный «Бастион Зиона» снимались из настоящего Canvas-рендерера на мобильном viewport 390 × 844. `map-1.png`–`map-6.png` получены автоматическим тестом; для проверки максимального уровня башни тест временно выдаёт энергию и принудительно завершает волну. `canvas-3.png`–`canvas-5.png` показывают новые поля без башен. Это тестовые состояния, не запись обычного прохождения.

`menu-reference-size.png` — скриншот браузера 390 × 608, `reference-390.png` — пропорционально уменьшенный эталон пользователя. В `visual-diff-final/` находится результат сравнения UI From Image. Поскольку в меню дополнительно размещён режим выживания и исходный фон отличается от изображения эталона, полного попиксельного совпадения нет.

`balance-1.jsonl`–`balance-5.jsonl` и `survival-balance.jsonl` — автоматические симуляции реального игрового движка с несколькими стратегиями. Они не заменяют пользовательского прохождения. `performance.json` — пятисекундный замер в desktop Chromium с мобильным размером экрана, не тест на физическом iPhone.
