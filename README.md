# NEO: Zion Defense

Браузерная tower-defense игра для портретного экрана и Telegram Mini App. Фанатский концепт, неофициальный продукт.

## Запуск

Установите Node.js 22 или новее, затем выполните `npm ci` и `npm run dev`. Откройте адрес, показанный Vite. Для проверки production: `npm run build` и `npm run preview`. Проект использует Canvas 2D и не требует сервера приложений. Настройки и открытые карты сохраняются локально; последняя завершённая волна, её экономика и постройки сохраняются локально; активная волна при перезагрузке начинается заново.

## Публикация

Создайте репозиторий `neo-zion-defense`, загрузите исходники в ветку main и в Settings → Pages выберите GitHub Actions. Workflow проверит и опубликует `dist`. Базовый путь по умолчанию `/neo-zion-defense/`; для другого имени установите переменную окружения `BASE_PATH` при сборке. Telegram настраивается по инструкции в TELEGRAM_SETUP.md.

## Ограничения

Графика сочетает оригинальные растровые атласы и Canvas-эффекты; анимация пока ограничена, это ещё не готовый коммерческий продукт. Баланс полной кампании, реальная работа в Telegram и на iOS требуют дополнительной проверки. Нет серверных таблиц лидеров и авторизации.

## Проверки браузера

Запустите `npm run dev` и в другом терминале `npm run test:mobile`. Тест использует установленный Chrome по пути `C:/Program Files/Google/Chrome/Application/chrome.exe`; при другом расположении измените путь в скрипте. Проверка десяти волн использует тестовый запас энергии и установки III уровня: это проверка устойчивости боевого цикла, а не подтверждение баланса обычного прохождения. Для проверки production-подпути запустите `npm run preview`, затем `node tests/production-smoke.mjs`.

В текущей версии графика использует отдельные растровые атласы и фон, но анимации спрайтов ограничены, дорога и опоры площадок построены поверх фоновой иллюстрации; камера поддерживает pan/zoom и фокус на Зионе, но фон не является трёхмерной сценой. Кампания целиком, баланс в ручной игре, производительность и безопасные области требуют испытаний на реальных устройствах и в Telegram. Это ещё не финальный коммерческий релиз.

### Проверка игрового процесса

После запуска `npm run dev` выполните `node tests/gameplay.mjs`, `node tests/telegram-camera.mjs` и `node tests/tower-roles.mjs`. При другом адресе Vite укажите переменную `ZION_URL`. Прогон десяти волн использует обычные стартовые ресурсы и автоматическое применение двух способностей; он не является ручным прохождением. Telegram в тесте имитируется, реальные устройства нужно проверить отдельно. Снимки Playwright лежат в `screenshots/`.
